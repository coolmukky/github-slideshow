Internal admin panel: service health, restarts, credential state, and logs across the estate. Reachable from the same edge as the customer apps, and it uses the same shared account — so admin power and agent identity are one.

Design-clinic note: this admin surface sits on the flat network behind the shared edge and authenticates as svc-halcyon — the same identity the agents use. Whoever holds that credential is both an agent and an administrator.
